# Canonical regression protocol

The canonical skill must pass the repository test suite, receipt-security checks, strict contract validation, complete mirror comparison, activation-case evaluation, and plugin validation before promotion.

`REVIEWED` requires the local review record and declared graders. `EVAL_PASS` additionally requires recorded 20/20/10 activation outcomes and an independent evaluator record. `PUBLISHED` additionally requires release approval whose version matches `lifecycle.json`. See [Lifecycle Policy](./lifecycle-policy.md).
